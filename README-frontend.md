# Lenguaje de Marcas

Descripción general de la aplicación web del CRM

## Tecnologías utilizadas 

(HTML5, CSS3, JavaScript)

## Requisitos previos

Navegador web (recomendado)
Editor recomendado: Visual Studio Code (compatible con cualquier editor)
No requiere instalación de dependencias ni conexión a BDD

## Instrucciones para Ejecutar

Clonar el repositorio
Abrir index.html directamente en el navegador
No requiere servidor local

### Firebase 

URL de la aplicación desplegada
Cómo acceder sin instalar nada

## Notas importantes

Los datos se gestionan con sessionStorage — se reinician al cerrar el navegador
Datos de ejemplo cargados por defecto al iniciar
Aclarar que la versión de Firebase es la versión de producción y la del repositorio es el código fuente
